# Magazine Library 1.3 原生发现页验证

交付：`dist/MagazineLibrary-1.3.0.apk`，versionCode 5。沿用原签名，在已授权的 HONOR BVL-AN20 上覆盖升级。

## 数据与界面

发现页改为 Java 原生组件，提供关键词搜索、分类、发布月份、封面、详情、同系列查询、本页排序、上一页、下一页和页码跳转。刊名与期号分开显示，分页控件固定在底部。输入结束后隐藏键盘，主窗口使用 resize，保留标题与导航的可见空间。

浏览器作为当前请求的数据通道：用户导航时加载对应响应，从响应形成的 DOM 提取字段；不扫描、遍历或预取全站页面。站点当前使用服务端 HTML 列表，因此没有另建重复的原生列表 HTTP 请求。封面也由同一个 WebView 请求，再缩小为原生图片。仅缓存最近 8 个访问响应，封面缓存上限 8 MB。

分类来自当前页面导航和条目标签。月份来自页面归档或当前结果，支持手动指定年月。关键词、分类和发布月份交给服务器筛选；排序只影响当前页。详情标签只取当前杂志的标签块，避免混入推荐条目的分类。

右上角「网页」保留浏览器入口。「返回原生」切回原生展示。出现明确验证页时使用网页让用户处理，成功得到杂志响应后可回到原生界面；后台验证不会强制切走书库或下载页。

## 文件准备与下载

原生 PDF 按钮使用选中链接的文字命名。当前网页的焦点预热和其脚本公开使用的文件准备请求，在原浏览器会话内建立下载凭据；准备后沿用原生后台下载、目录选择、文件校验与书库入库。

普通 VK 跳转保留「等待跳转」状态，不能因跳转等待直接归为「需要验证」。确实要求验证时保留网页供用户完成。未使用自动 CAPTCHA 处理。

去重同时检查原始链接和跳转后的文件地址。清空下载历史保留书库，后续点击同一原始 PDF 链接也能识别已下载条目。
