# Magazine Library 1.2.1 清空记录验证

交付 APK：`dist/MagazineLibrary-1.2.1.apk`，versionCode 4，沿用现有签名覆盖升级。设备：已授权的 HONOR BVL-AN20。

下载页上方增加「清空记录」，一次点击清理已完成和失败的记录。未完成任务保留，包括排队、下载中、暂停、等待跳转和需要验证。没有可清理记录时按钮禁用。清空操作不删除 PDF、书库条目、分类、目录授权或阅读进度。

数据库升级到 v4，新增独立的下载历史显示标志。书库和重复下载检查继续使用完整条目；重新排队的任务恢复历史显示，新任务正常显示。清空通过一条带状态条件的数据库更新完成，保留未完成任务，避免根据界面旧状态清理正在重试的下载。

## 设备验证

执行 `history` 仪器测试，通过真实下载页按钮操作独立测试数据库，避免清空用户自己的记录。测试 PDF 在应用缓存创建，测试结束删除临时数据库及 PDF，并恢复临时修改的显示配置。

- 从 v3 数据库升级后，原记录可见，书名、分类、文件地址和阅读位置保留。
- 单次点击清空后，已完成和失败记录从下载页消失，全部五种未完成状态保留。
- 关闭并重新打开数据库，已清空记录继续隐藏。
- 已下载测试 PDF 的 SHA-256、页数与可读性不变，书库仍显示该书，分类和阅读进度不变。
- 清空后再次添加同一个已完成链接不会产生重复书籍。
- 重新排队的失败任务恢复显示，新下载正常显示。
- 「未完成」筛选下清空仍能清理隐藏在筛选范围外的完成记录。
- 没有下载记录时显示空状态，并禁用清空按钮。
- 用户原有书籍元数据与历史记录保留，测试不删除用户 PDF。
